# 隐私政策 · 悬浮虚拟扫描枪

最后更新：2026-11-06
适用版本：0.2 及以后

## 一句话概括

这个 App **不收集任何个人数据**、没有广告、没有统计 SDK、不做用户画像。
扫描内容、常用指令和配置档都只存在你手机本地；唯一的联网行为是你在「网络转发」里自己填写的地址。

## 一、本 App 会接触到什么

| 数据 | 用途 | 是否离开手机 |
|---|---|---|
| 相机画面 | 识别条码/二维码（ML Kit 离线解码） | **否**。画面不解码成文件、不上传 |
| 整页扫描拍的照片 | 一次解码整页条码 | **否**。只在内存中解码，用完立即释放，不写入相册 |
| 扫描到的条码内容 | 注入到目标 App，并记入本机扫码历史 | **否**（除你主动开启「网络转发」，见第四节） |
| 常用指令、配置档、设置 | 本地保存，方便换目标 App 时切换 | **否**。存于 SharedPreferences，卸载即删除 |
| 扫码历史 | 本机 SQLite，最多 500 条，可逐条删除或一键清空 | **否** |

## 二、权限与用途

| 权限 | 为什么需要 | 可否拒绝 |
|---|---|---|
| 相机 `CAMERA` | 扫描条码。只在悬浮窗打开时使用 | 不可（没有相机就无法扫码） |
| 悬浮窗 `SYSTEM_ALERT_WINDOW` | 把扫描面板浮在目标 App 之上，且不抢输入焦点 | 不可（这是本 App 的核心形态） |
| 无障碍服务 `BIND_ACCESSIBILITY_SERVICE` | 把扫到的文本写进当前输入框 | **可以**。拒绝后可改用 Shizuku 或"仅剪贴板" |
| 通知 `POST_NOTIFICATIONS` | Android 要求前台相机服务必须有常驻通知 | 可以（Android 13+ 会降低服务存活率） |
| 蓝牙 `BLUETOOTH_CONNECT` / `BLUETOOTH_ADVERTISE` | 仅「蓝牙键盘输出」使用：手机充当电脑的蓝牙键盘 | **可以**。不启用该输出时不会申请 |
| 网络 `INTERNET` | 仅「网络转发」使用：把条码发到你自己的电脑 | 可以。不启用该功能时不会产生任何流量 |

无障碍服务是本 App 功能最强的权限，因此说明写在这里：它**只做两件事**——读取当前窗口里可编辑输入框的位置，
把扫码得到的文本写进去；以及判断顶层是否有弹窗（避免按键被弹窗吞掉）。
本 App 不会读取你的聊天记录、不采集界面文字、不监听按键、不把任何界面内容传出手机。
源码公开在 https://github.com/ethanleellj/FloatingVirtualScannerGun ，可自行核对。

## 三、数据存储与删除

- 全部数据存在应用私有目录（`/data/data/com.virtualscanner.gun/`），其他应用无法读取。
- 卸载 App 即全部删除；也可在「扫码历史」里逐条删除或清空。
- 本 App 不提供账号体系，因此不存在"云端删除"的问题——本来就没有云端。

## 四、联网行为（只在两种情况发生）

1. **网络转发**：你填写 PC 的 IP 与端口后，扫码内容会通过 TCP 发往该地址。数据只到你指定的那台机器，
   本 App 不缓存、不转发到第三方。关闭开关后立即停止。
2. **系统组件**：相机、条码识别（ML Kit）都在本机完成。ML Kit 为离线模型，不含网络调用。
   本 App 自身不含任何统计、崩溃上报、广告 SDK。

## 五、第三方组件

| 组件 | 作用 | 许可 |
|---|---|---|
| CameraX | 相机预览与拍照 | Apache-2.0 |
| ML Kit Barcode Scanning | 离线条码/二维码识别 | Google ML Kit 条款（离线模式） |
| Shizuku | 可选的 shell 注入通道 | Apache-2.0 |
| AndroidX | 基础 UI 库 | Apache-2.0 |

## English summary

This app collects no personal data. Camera frames are decoded on-device by ML Kit and never uploaded;
scanned codes, snippets, profiles and history stay in the app's private storage and are removed when you
uninstall. The only network traffic is the TCP address you configure manually under "Network forwarding".
The accessibility service is used solely to write scanned text into the focused input field and to detect
blocking dialogs. No analytics, no ads, no crash reporting.
